## Landmines / gotchas

- **Plugin `source` must not point at the monorepo root.** `.claude-plugin/marketplace.json` pointing a plugin's `source` at `./` makes Claude Code copy the WHOLE repo into the plugin cache and run `npm ci` there whenever a `package.json`+lockfile sit at that root — measured 413 MB / 45s for a payload that was one 8.6 KB skill file + a 10-line `.mcp.json` (gate `docs/adversarial/agent-skill-gate-2026-08-23.md` B1).
