# plugins

Claude Code plugins distributed by the root `.claude-plugin/marketplace.json`. Each plugin gets its own small root so installing it doesn't copy the whole monorepo into the user's plugin cache (see B1, `docs/adversarial/agent-skill-gate-2026-08-23.md`).

- [`coldrig/`](./coldrig/) — the Coldrig plugin (MCP config + the `skills/coldrig` skill). See its own [README](./coldrig/README.md).
