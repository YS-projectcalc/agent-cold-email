# hard-builder memory index

## Failure mechanisms (check before diagnosing a hard case)
- [code-with-no-production-driver-passes-every-test](code-with-no-production-driver-passes-every-test.md) — ⚠️ CLASS: a feature whose only caller is an entry point PRODUCTION never invokes (ColdStart `runTick`) is 100% green and 100% dead; tests call it directly so no suite sees it. Grep the caller chain out to a real trigger (cron/route/tool/alarm) before claiming shipped.
- [vendor-cancel-needs-marker-and-attempt-cap](vendor-cancel-needs-marker-and-attempt-cap.md) — a one-shot vendor action fired off a COMPUTED transition (day>28) is a predicate, not an edge → re-fires every tick without a persisted marker; marker AFTER confirm, cap the retries (new infinite-retry path otherwise), and keep vendor I/O OUT of the sync refresh the send path calls.
- [guards-inline-in-a-loop-are-not-a-policy](guards-inline-in-a-loop-are-not-a-policy.md) — CLASS: governance written INLINE in a batch loop (tick caps/pause/suppression) is unenforced on every OTHER path to the same effect; sweep call sites of the guarded EFFECT (`adapters.email.send`), never the guard. Cap-check-then-`await` is a TOCTOU → one conditional UPDATE as check-and-reserve.
- [coldstart-per-tick-recompute-clobbers-control-state](coldstart-per-tick-recompute-clobbers-control-state.md) — a per-tick refresh that recomputes a column (warmup daily_cap/status) silently wipes any control-loop override written to the SAME column; keep loop state in a SEPARATE column + have the refresh honor it (MIN).
- [coldstart-suspend-auth-split-do-vs-d1](coldstart-suspend-auth-split-do-vs-d1.md) — ColdStart: DO `tenant_profile.status='suspended'` does NOT lock the token (requireAuth reads D1 `tenants_index.status`); flip BOTH to truly disable a tenant, or a "suspended" tenant re-provisions.
- [backtick-inside-template-literal-sql](backtick-inside-template-literal-sql.md) — a backtick in a backtick-delimited SQL template literal (even in a `--` comment) ends the string → misleading TS1005 errors; never backtick-quote inside a template literal.
- [sandbox-port-masks-real-server-contract](sandbox-port-masks-real-server-contract.md) — ColdStart A5 spike: the in-process sandbox EmailPort hides 4 real-server obligations (reconstruct threadId from headers, set real RFC5322 Message-ID, at-least-once re-poll dedupe [events table has none], soft-vs-hard bounce) + SendEmailInput can't carry List-Unsubscribe; validate against a real SMTP/IMAP server before freezing a port.
- [async-tally-reset-on-triggering-action](async-tally-reset-on-triggering-action.md) — resetting a counter on the SAME action that async-feeds it (soft-bounce streak DELETE'd on every send, bounce polled AFTER) makes the threshold unreachable; reset only on an independent POSITIVE signal (reply), clear on permanent-suppress. A single-tick multi-lead fixture hid it — needs a real over-time single-lead trace.
- [dsn-arf-fields-live-in-mime-subparts](dsn-arf-fields-live-in-mime-subparts.md) — DSN/ARF report fields (Final-Recipient, Original-Rcpt-To, Status) live in MIME SUB-PARTS, not the outer header block; an RFC 5322 top-level header parser silently returns empty for them → use a whole-source line-anchored scan. (ColdStart engine classify.ts.)
- [persist-before-confirm-cross-boundary](persist-before-confirm-cross-boundary.md) — CLASS: a cursor/claim/status persisted BEFORE the cross-boundary effect (vendor call / HTTP response / DO commit) is confirmed → work silently lost or row stuck on crash. Fix: consumer-owned cursor advanced only inside the same txn as the confirmed work, OR persist-after-confirm. Members: engine poll cursor, tick send-on-'sending', idempotency 'pending', I3 billed-mailbox cred-push (record BEFORE push, F6).
- [json-store-corrupt-catchall-silent-empty](json-store-corrupt-catchall-silent-empty.md) — CLASS (F5): a JSON durable store whose loader catches ALL errors → empty silently drops state on corruption AND overwrites the only copy on next flush; split MISSING (ENOENT→empty) from CORRUPT (parse/shape error→THROW, refuse to boot). Members: engine-state.json, pushed-mailboxes.json.
- [period-keyed-counter-for-persistent-resource](period-keyed-counter-for-persistent-resource.md) — CLASS both directions: a per-period counter gating a PERSISTENT resource over-allocates after rollover (G4 plan slots), AND a LIFETIME counter driving a per-episode decision never resets (dunning cycle 4 suspends a recovered payer on failure #1). Match counter scope to decision scope; store an episode basis as the counted table's ROWID, not a timestamp.
- [compaction-snapshot-must-carry-inflight-state](compaction-snapshot-must-carry-inflight-state.md) — CLASS: a periodic compaction snapshot that discards its source log MUST serialize every UN-RESOLVED in-flight entry (not just terminal state), else rotation silently drops mid-flight work → crash re-opens the very double-send the log closes. (Pre-send intent log B1: snapshot needs a `danglings` slot.)
- [adapter-selected-from-column-before-same-request-update](adapter-selected-from-column-before-same-request-update.md) — a vendor port SELECTED/baked from a persisted column at request-entry (buildAdapters) that the SAME request later UPDATEs is one-call-stale (prior call's opt-in/registrant): fresh opt-in→false registrar_unarmed 503+alert, opt-out→stale real buy. Fix: re-select ONLY that port from THIS call's input for the authoritative flow; hand-built-adapter tests are structurally blind (drive the real HTTP path). (Registrar-arming B1.)

- [half-a-vendor-contract-invoked-on-the-other-half](half-a-vendor-contract-invoked-on-the-other-half.md) — ⚠️ CLASS (the customer-P0 incident): an adapter implementing ONE half of a two-half vendor contract (connect-existing-domain NS flow) invoked ONLY on the other half (vendor-registered domains) → wrong op, throws forever, graded retryable → 24h customer loop. Enabler = the discriminator (`connection_type`) DROPPED at the port type boundary. Invisible because every fixture modelled transient-then-success and the sandbox models "call returned == resource exists".
- [rpc-boundary-strips-class-identity](rpc-boundary-strips-class-identity.md) — ⚠️ an error thrown in the DO reaches the Worker with own props but NO prototype (`remote:true`), so `instanceof` is FALSE at the HTTP surface; error-response.ts branches on `err.name` for exactly this reason. A new error-grading helper using instanceof graded every retryable vendor failure as non-retryable in the customer body — only the real-HTTP-route test caught it.
- [merge-of-prerefactor-lane-reverts-sibling-fix](merge-of-prerefactor-lane-reverts-sibling-fix.md) — CLASS: merging a lane written against a PRE-refactor file; taking the incoming side of a moved-function conflict silently REVERTS the refactor lane's fix inside that function, and clean textual auto-merge still leaves unimported/dead symbols + stale fixtures. Typecheck first, then the incoming lane's own tests, then a revert-proof; reconcile test counts against each lane's reported numbers.
- [customer-safe-translator-gated-on-error-shape](customer-safe-translator-gated-on-error-shape.md) — CLASS: a sanitizing error translator invoked behind a shape predicate (`err instanceof Error ? err.name : ""` + `if (name !== "")`) leaves a raw `String(err)` fallthrough — a non-Error throw leaks vendor identity verbatim to the customer. Delete the gate (translator already takes `unknown`); keep a named-class control test so the fix doesn't flatten everything to `internal`.
- [false-recovery-disarms-cooldown-dedup](false-recovery-disarms-cooldown-dedup.md) — CLASS: clearing an incident on the vendor ACCEPTING a remedy (not on the condition being fixed) lies AND silently disarms a cooldown dedup — the healthy transition resets the state machine, so the next failure alerts again. Clear only where the goal state is proven; give a remedy's outcome its OWN check name.
- [fixture-decorates-vendor-owned-object](fixture-decorates-vendor-owned-object.md) — ⚠️ CLASS: a fixture that puts OUR field on a VENDOR-MINTED object (metadata.tenantId on a Stripe Invoice/Dispute) restates the parser's premise instead of testing it → 1271 green tests, two billing lanes dead in LIVE prod. Ask who mints the object; rebuild from vendor docs; tripwire-scan test sources.
- [guard-scoped-wider-than-the-state-it-protects](guard-scoped-wider-than-the-state-it-protects.md) — ⚠️ CLASS (I shipped it; gate caught it): a staleness/dedup guard keyed GLOBALLY over independent state machines silences them all — a routine renewal made a real chargeback freeze a permanent no-op. Key the guard to the state it protects; refuse only on an ACTUAL state conflict; alert on every 200-refusal.
- [completion-pass-must-recheck-ordering](completion-pass-must-recheck-ordering.md) — a reconcile pass that "finishes crashed work" is a SECOND write path that bypasses the primary path's guards → resurrects state a newer event superseded; re-apply every pre-effect guard, key appended rows on the event id.
- [sandbox-fallback-masks-a-missing-activation-gate](sandbox-fallback-masks-a-missing-activation-gate.md) — ⚠️ CLASS: a missing gate that degrades to a SANDBOX adapter makes "no vendor call" TRUE on the broken code too; the harm is a fabricated 'sent' row → assert the ROW's status, not the call count. A revert-proof showing fewer failures than expected means PROBE, not "the belt covers it".
- [polling-check-error-is-indistinguishable-from-negative](polling-check-error-is-indistinguishable-from-negative.md) — CLASS: a poll whose ERROR looks like its NEGATIVE (empty stdout + `2>/dev/null`) reports "all clear" while broken; macOS bfs rejects relative `-newermt '-90 seconds'` → use md5-hash polling or a `touch`-ed `-newer REF`, keep stderr visible, and corroborate a quiet tree with `ps -p` (agent awaiting a 4min vitest writes nothing).
- [fail-loud-throw-after-billed-vendor-call](fail-loud-throw-after-billed-vendor-call.md) — CLASS: a new validation throw placed AFTER a billed vendor call but BEFORE its durable marker turns a rare crash window into a deterministic re-charge loop if graded retryable; grade non-retryable + report the created-but-unmarked residual.
- [exemption-inherits-none-of-the-guards-reasoning](exemption-inherits-none-of-the-guards-reasoning.md) — ⚠️ CLASS: an EXEMPTION carved into an ordering guard for the cross-OBJECT case exempts the same-OBJECT reverse order too → a late `dispute.created` after its own closed(won) wrote a terminal 'disputed' nothing can lift (permanent tenant brick). Bound it to the entity's OWN recorded lifecycle, and make sure the write path actually records it (UPDATE-that-hits-0-rows leaves no witness).
- [caller-side-effect-gated-on-callee-result-field](caller-side-effect-gated-on-callee-result-field.md) — CLASS: a caller-side flip gated on a result field (`if (result.plan) switchToRealClock()`) silently stops firing once the callee gains a return path that APPLIES the effects but reports `duplicate:true` with no `plan`; neither lane's tests can see it. Grep callers of any applier that gains a return path.

## Test-env gotchas (ColdStart apps/platform vitest)
- [coldstart-vitest-binding-and-d1-isolation-gotchas](coldstart-vitest-binding-and-d1-isolation-gotchas.md) — a wrangler.toml binding IS bound in the vitest env (not undefined; asserting `.toBeUndefined()` throws RPC inspect errors) → test factory branches with fake envs; direct `env.DB` writes are NOT rolled back per-test → `beforeEach` DELETE for state-machine tables; `test/setup.ts` needs each new migration added by explicit `?raw` import.
- [do-constructor-and-query-order-test-gotchas](do-constructor-and-query-order-test-gotchas.md) — `evictDurableObject` is the only way to test DO CONSTRUCTOR behavior for real; a throwing stub RPC pollutes the run with an unhandled `remote:true` rejection (assert on the instance instead); an un-ORDER-BY'd query returns INDEX order (partial unique idx), not rowid. Carries the U1 answers: transactionSync commits AND rolls back in a constructor; a NaN bind to INTEGER NOT NULL is rejected.
- [vitest-pool-workers-ambient-devvars-leak](vitest-pool-workers-ambient-devvars-leak.md) — CLASS: the pool auto-loads `apps/*/.dev.vars` via wrangler and injects EVERY key as a test binding → a dev's ambient real secret (truthy STRIPE_SECRET_KEY) flips a behavior gate under test; fix = CONSTRUCT `miniflare.bindings` from an allowlist, neutralize non-allowlisted ambient keys to `null` (nullish+JSON-valid, not `""`/`undefined`); hermetic-by-default + canary guard.

## Build techniques
- [failing-by-construction-env-coverage-guard](failing-by-construction-env-coverage-guard.md) — R3-1: enforce "a new vendor env binding must wire into isRealSpendArmed" with a test that `?raw`-parses env.ts source: tag fields `// spend-arming`, assert each tagged field is referenced in the guard fn AND every env field is categorized (tagged ∪ allowlist == all) so the NEXT binding trips RED. Needs `declare module "*.ts?raw"`.
- [coldstart-engine-crash-injection-idiom](coldstart-engine-crash-injection-idiom.md) — deterministic engine crash tests: model a crash by injectable faulty SendLog (`makeSendLog` opt) + DISCARD-store-rebuild-from-disk (crash lives at the durability layer, not a throw); ControllableSmtp stalls key B so live compaction fires mid-flight; asymmetric append order (intent APPEND-first fail-closed / recorded MEMORY-first 200-off-memory); out-of-proc SIGKILL variant imports dist behind ENGINE_KILL_E2E. NB: engine vitest is plain-node + ~30s ESM transform → a combined typecheck+test can blow a 120s timeout WITHOUT hanging (read verbose before diagnosing a hang).

## Build patterns / gotchas (ColdStart engine)
- [stripe-percent-coupon-prorates-at-unit-level](stripe-percent-coupon-prorates-at-unit-level.md) — a percent coupon discounts RECURRING lines via `discount_amounts` (gross line) but bakes the discount INTO the PRORATION line `amount` (desc "(with X% off)", discount_amounts=0), so `total != subtotal×(1−pct)`; assert the bumped recurring line's discount + a proration desc `/% off/i`. A decrease-no-credit test must run on a FRESH sub (an increase proration emits a "-Unused time" credit component). (quantity-billing Tier-2 gate.)
- [coldstart-authed-route-needs-path-pattern-and-zod-default-output-required](coldstart-authed-route-needs-path-pattern-and-zod-default-output-required.md) — a new authed route 500s (not 401) until its literal path is added to `AUTHED_PATH_PATTERNS` in index.ts (per-path requireAuth, never blanket `*`); AND `z.X().default(v)` makes the field REQUIRED in the inferred OUTPUT type → every direct-engine-call test must supply it.
- [coldstart-mailcomposer-single-builder-for-transports](coldstart-mailcomposer-single-builder-for-transports.md) — new send transports (Gmail/Graph API) must carry compliance headers byte-identically: reuse nodemailer's MailComposer as the ONE raw-message builder (deep import + @types both work); map all API failures to the SMTP path's UpstreamTransientError.
- [coldstart-env-example-gitignored-and-header-folding](coldstart-env-example-gitignored-and-header-folding.md) — `.env.example` is gitignored by `.env.*` (durable docs → README); long MIME headers fold across lines (assert fold-tolerantly, not single-line).
